Ruina - download on win11

1. RPG2000RTA

원작자가 RPG2000RTA 를 이용하여 게임을 개발했기에 이는 필수 입니다.
게임을 다운로드 해보면 아시겠지만, 원래의 RPG2000RTA 의 다운로드 페이지가 삭제되어 다운로드가 불가합니다.
또한 공식 사이트(?)에 있는 rta2000 파일을 win11 이 지원하지 않는것 같습니다. (이것 때문에 3시간 날렸다)
그리하여 다음 링크를 통해 특수한 방법으로 다운로드를 받겠습니다.

usasda.tistory.com/12
1. RTP2000.exe 설치
2. rtp1320.exe 설치
3. RTP.zip 다운받은후 압축 풀기
4. RTP 파일을 영문 RTP 파일에 덮어쓰기

github.com/xupefei/Locale-Emulator/releases

kr.bandisoft.com/bandizip

4. Ruina

www.freem.ne.jp/win/game/2037
Download 아래 Windows 클릭
-> Ruina121.zip 파일 다운받음

5. 실행

Ruina121.zip 우클릭
-> 반디집으로 열기

반디집 오른 위 코드페이지 클릭
-> 일본어 클릭 (또는 자동 클릭) *필수*
-> 압축풀기

cmd 에서 해당위치로 이동후 dir 으로 파일명 확인
( 원인은 모르겠으나 저는 제가 할 수 있는 모든것을 했봤지만 파일이 보이지 않았다. 파일이 보인다면 해당 과정은 생략해도 좋다. )
-> dir Ruina121
-> 주소 복사
( 예시 : C:\Ruina121 )

파일탐색기
-> 주소 붙여넣기
-> start.exe 우킬릭
-> 추가옵션
-> 로케일 에뮬레이터
-> Run in Japanese (Admin) 클릭 *필수*
