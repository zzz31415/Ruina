Ruina - download on win11

1. RPG2000RTA

因原作者使用 RPG2000RTA 开发， 此项为必须
因原 RPG2000RTA 下载网站被删， 无法下载原版。
win11 似乎不支持某 rta 官网（推测）的 rta2000 文件。(害我白费三个点)
因此在这里我将通过以下网址来使用特殊方法来下载

usasda.tistory.com/12
1. 下载并安装 RTP2000.exe
2. 下载并安装 rtp1320.exe
3. 把 RTP.zip 下载后解压
4. 把解压后的 RTP 文件覆盖原本的英文 RTP 文件

2. Locale-Emulator (v2.5.0.1)

github.com/xupefei/Locale-Emulator/releases
运行 LEInataller.exe
-> 点击 Install for current user

3. bandizip (如若有其他可使用的解压方式则不需此项)

kr.bandisoft.com/bandizip
-> 点击 "무료다운로드"

4. Ruina

www.freem.ne.jp/win/game/2037
点击 Download 下方 Windows
-> 下载 Ruina121.zip 文件

5. 运行

右键点击 Ruina121.zip
-> 点击 "반디집으로 열기" (译 : 使用 "반디집" 打开)

点击 "반디집" 右上角 "코드페이지" 클릭
-> 点击 "일본어" (或 "자동선택") (此处日文为 CP932 )*必*
-> 点击 "풀기" (意 : 解压)

在 cmd 中移动到该位置后写入命令 dir 确认解压后的文件名
( 不知原因， 就算我力尽所能也无法看见解压后的文件。 如果解压后可直接看见又能打开则可无视此项)
-> dir Ruina121
-> 复制文件位置
( 列 : C:\Ruina121 )

文件夹
-> 粘贴文件位置
-> 右键点击 start.exe
-> 点击 "추가옵션" (译 : 附加项)
-> 鼠标滑动到 "로케일 에뮬레이터"
-> 点击 Run in Japanese (Admin)*必*
